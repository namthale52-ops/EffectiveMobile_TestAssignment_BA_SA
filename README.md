# Test Assignment (BA + SA)

## 🎯 Цель
Демонстрация навыков бизнес- и системного анализа (моделирование, требования, API, алгоритмы).

## 📂 Структура репозитория
- **Task 1**: BPMN-модель процессов поддержки (`AsIs.svg`) и аналитический комментарий (`.pdf`).
- **Task 2**: User Story, Use Case и BPMN-диаграмма публикации товара (`.pdf`, `.svg`).
- **Task 3**: OpenAPI-спецификация (`.yaml`) и алгоритм backend-логики регистрации (`.pdf`).

## 📝 Особенности и Итог
Исходные требования структурированы и переведены в ключевые артефакты аналитика (модели BPMN, User Story/Use Case, OpenAPI, алгоритмы) с единым стилем наименований `TaskX_...`. Полное содержимое файлов доступно в репозитории.
